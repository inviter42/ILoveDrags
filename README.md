# ILoveDrags
A small plugin that fixes dragging behavior in older PH plugins.

## Installation

Download and install:

1. Download and install the dependent version of [BepInEx](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.22).
1. Download the latest release, unzip the archive, drag and drop the contents into the game directory.

The plugin has a MoreAccessories dependency.

It is highly recommended to use a BetterRepack, as the new releases are getting tested against it.

## Bugs and Issues
If you found a bug, file a bug report on GitHub with description, logs (`PlayHome/output_log.txt`) and reproduction steps if possible.
